# RobloxUWP-Frontend

A little project i thought of in like 2026/03 or 05, basically a remake of UWP frontend that would feel almost the same to use as the original binary.

## Features
- Login system and Sign Up (Not fully finished)
- A 3D demo of a cube spinning with information like mouse pos and game parameters
- A decompilation for the AppBridge Cpp files (if ever needed)
- The exactly the same page look, everything cosmetically is identical
